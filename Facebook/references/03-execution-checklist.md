# 03 · Checklist thực thi

| Bước | Input → output | Gate |
|---|---|---|
| 1 | Owner objective → WO có scope, cost, expiry | Không có WO thì chưa là execution job |
| 2 | Source registry → pinned truth/rights | Legacy/conflict không được approved |
| 3 | Customer need → hypothesis/brief | KPI, stop rule, một message |
| 4 | Brief → caption/script/storyboard draft | Không bịa facts hoặc testimonials |
| 5 | Asset sources → media thật + generation receipts | License, cost, product fidelity |
| 6 | Toàn bundle → QA độc lập | Truth, rights, quality, destination, policy đều pass |
| 7 | Canonical payload → approval request | Bind actor/target/env/revision/digests/time |
| 8 | Signed receipt → execution reservation | Signer trusted, no self-approval, nonce/lease |
| 9 | Executor recheck → provider request | Kill state fresh, limits, expiry, exact bytes |
| 10 | Provider response → reconciliation record | Unknown không retry mù |
| 11 | Published verified → metric snapshots | Source timestamp/coverage/version |
| 12 | Metric + ledger → learning | Không lấy engagement làm realized profit |

Release bootstrap chỉ thực hiện planning/preview và validation offline. Bước 5–12 cần adapter/runtime/evidence production riêng, không phải để agent bỏ qua khi thấy script đã có.

Trước schedule phải biết account type, timezone, slot, media digest và validity của offer/rights/approval. Đến giờ phải kiểm lại toàn bộ, không duyệt lúc tạo lịch rồi quên. Trễ slot cần replan, không đăng bù.

Bundle production chứa brief, copy, source/claims/rights, real media checksums, QA findings, approval, request, receipt, reconciliation và metrics. Chỉnh caption/link/media/target/time tạo revision mới. Export draft luôn ghi NOT_FOR_PUBLICATION.

Handoff report: WO id, bước cuối thật sự hoàn thành, artifact digest, tests run/not run, blockers, decision và external effects. Không ghi DONE/PUBLISHED nếu chỉ có queue record hoặc stdout.
